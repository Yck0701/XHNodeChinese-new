# 虚幻翻译插件

用于 Niagara、材质和蓝图的界面翻译与中英文搜索。

**[安装说明、维护记录和下载入口：金山文档](https://365.kdocs.cn/l/cpi4ASG5Izsi?source=wiki)**

新用户：打开上面的文档，按“第一次用，只看这里”的四步安装即可。

软件本体可在金山文档中直接下载金山云附件；安装工具的版本发布与自动更新仍由 GitHub 提供。本仓库保留自动更新需要的安装包、共享词库和更新清单。产品说明与维护记录统一在金山文档更新，源码单独保存在私有仓库。
